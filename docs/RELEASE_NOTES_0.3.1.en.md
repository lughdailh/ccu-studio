# CCU Studio 0.3.1

The first release published under the **CCU Studio** name.

## What's new

- New CCU Studio identity throughout the interface and packages.
- Built-in quick help in Catalan and English, selected from the OBS locale.
- Discreet shortcuts for instructions and project support.
- Optional PayPal donation button.
- `GPL-2.0-or-later` licensing.
- Transparent credit for assistance from OpenAI Codex/ChatGPT and Claude.
- Compatibility with filters and settings created by CCU OBS 0.3.0.

The technical names `obs-ccu`, `ccu_obs_color_filter`, and the installation
paths are retained in this release to avoid breaking existing scenes and
upgrades.
