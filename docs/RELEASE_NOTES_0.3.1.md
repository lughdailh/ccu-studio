# CCU Studio 0.3.1

Primera versió publicada amb el nom **CCU Studio**.

## Novetats

- Nova identitat CCU Studio a la interfície i als paquets.
- Ajuda ràpida integrada en català i anglès, segons l'idioma d'OBS.
- Accessos discrets a les instruccions i al suport del projecte.
- Botó de donació voluntària mitjançant PayPal.
- Llicència `GPL-2.0-or-later`.
- Crèdits transparents per l'assistència d'OpenAI Codex/ChatGPT i Claude.
- Compatibilitat amb filtres i configuracions creats amb CCU OBS 0.3.0.

Els noms tècnics `obs-ccu`, `ccu_obs_color_filter` i les rutes d'instal·lació
es conserven en aquesta versió per evitar trencar escenes i actualitzacions.
