# CCU Studio 0.3.2

## Canvis

- El bundle de macOS passa a dir-se `ccu-studio.plugin`.
- La carpeta i la DLL de Windows passen a dir-se `ccu-studio` i
  `ccu-studio.dll`.
- Crèdits complets incorporats al final de les instruccions en català i
  anglès.
- Web oficial del projecte incorporada a la interfície i la documentació.

## Actualització des d'una versió anterior

Tanca OBS i elimina l'antic `obs-ccu.plugin` a macOS o la carpeta `obs-ccu` a
Windows abans d'instal·lar CCU Studio 0.3.2. L'identificador intern del filtre
de color es conserva perquè les escenes existents continuïn reconeixent-lo.
