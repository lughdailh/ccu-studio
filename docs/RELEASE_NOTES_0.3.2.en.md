# CCU Studio 0.3.2

## Changes

- The macOS bundle is now named `ccu-studio.plugin`.
- The Windows folder and DLL are now named `ccu-studio` and
  `ccu-studio.dll`.
- Full project credits added to the end of the instructions in Catalan and
  English.
- The official project website is now available from the interface and docs.

## Upgrading from an earlier release

Close OBS and remove the old `obs-ccu.plugin` on macOS or the `obs-ccu`
folder on Windows before installing CCU Studio 0.3.2. The internal color
filter identifier remains unchanged so existing scenes can still recognize
it.
